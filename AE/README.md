# AE playground

Ten sam styl co `Language_RNN`: `train.py` z klasą opakowującą (`AutoencoderNet`), `trainn` / `evall`, `main.py` z `experiment` + `default_run` + Manual Stuff.

Sieci implementujesz w `src/models/` (`vanilla_ae`, `denoising_ae`, `vae`, `ddpm`) — klasy jak `rnnLSTM` (`name()`, `description()`, `forward`).

```bash
source ./activate.sh
./start
```

`old_stuff/mnist.py` — stary SimpleNet (klasyfikacja), bez zmiany koncepcji.
